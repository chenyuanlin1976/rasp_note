# AIDL Steps

Using AIDL (Android Interface Definition Language) in an Android Studio project targeting Android 14 (API 34/35+)  
follows standard IPC (Inter-Process Communication) mechanics, but with modern build features enabled.

Here is a complete step-by-step guide using Kotlin.

## Step 1: Enable AIDL in Build Configuration

In modern versions of Android Studio, AIDL compilation is built into the Gradle build features block.  
Open your app-level `build.gradle.kts` (or build.gradle) and make sure aidl is enabled under buildFeatures:  
**Sync your project with Gradle files after making this change.**

```ini
android {
    namespace = "com.example.aidldemo"
    compileSdk = 34 // or higher for Android 14+

    defaultConfig {
        applicationId = "com.example.aidldemo"
        minSdk = 24 // AIDL works on all supported modern SDKs
        targetSdk = 34
        // ...
    }

    buildFeatures {
        aidl = true  // Explicitly enable AIDL compiler
        // viewBinding = true / compose = true (depending on your setup)
    }
}
```

## Step 2: Create the AIDL File

In the Android Studio Project panel, switch to the **Project** or **Android** view.Navigate to `app/src/main/`.  
If an **aidl** directory doesn't exist parallel to java, create it.Inside `src/main/aidl/`,  
create a package directory matching your app's package structure (e.g., `com/example/aidldemo`).  
Right-click the package folder **New >> AIDL >> AIDL File**, and name it `IMyAidlInterface.aidl`.  
Alternatively, write the contents manually inside `IMyAidlInterface.aidl`:

```java
// Package name must match your directory path
package com.example.aidldemo;

interface IMyAidlInterface {
    // Define the methods you want to expose for IPC
    int add(int a, int b);
    String getMessage(String name);
}
```

## Step 3: Rebuild the Project

Go to the top menu and select Build **Rebuild Project**.  
This prompts the Android SDK to automatically generate a matching Java/Kotlin **binder interface** (`IMyAidlInterface.java`)  
inside your build directory (app/build/generated/source/aidl/...).

## Step 4: Implement the AIDL Service

Create a standard Android Service that will handle client requests.  
Inside this service, implement the inner abstract class `IMyAidlInterface.Stub`:

```kotlin
package com.example.aidldemo

import android.app.Service
import android.content.Intent
import android.os.IBinder
import android.util.Log

class MyAidlService : Service() {

    // Implement the Stub generated by the AIDL compiler
    private val binder = object : IMyAidlInterface.Stub() {
        override fun add(a: Int, b: Int): Int {
            Log.d("MyAidlService", "add requested: $a + $b")
            return a + b
        }

        override fun getMessage(name: String?): String {
            return "Hello from Android 14 AIDL Service, ${name ?: "Guest"}!"
        }
    }

    override fun onBind(intent: Intent?): IBinder {
        return binder
    }
}
```

## Step 5: Declare the Service in AndroidManifest.xml

Ensure your service is declared inside the `<application>` block

**Android 14+ Note**: If your service is meant to be explicitly called by your own app, keep exported="false".  
If another separate application needs to bind to this service across app boundaries, set exported="true",  
and consider adding a custom permission or appropriate intent filtering to secure it.

```xml
<application
... >
    <service
        android:name=".MyAidlService"
        android:exported="true" /> <!-- Set to true if querying from another app -->
</application>
```

## Step 6: Bind and Consume the Service from a Client (e.g., MainActivity)

In your Activity or client component, bind to the service using `bindService()`  
and convert the resulting IBinder using IMyAidlInterface.Stub.asInterface(service).

```kotlin
package com.example.aidldemo

import android.content.ComponentName
import android.content.Context
import android.content.Intent
import android.content.ServiceConnection
import android.os.Bundle
import android.os.IBinder
import android.util.Log
import androidx.appcompat.app.AppCompatActivity

class MainActivity : AppCompatActivity() {

    private var aidlService: IMyAidlInterface? = null
    private var isBound = false

    private val connection = object : ServiceConnection {
        override fun onServiceConnected(className: ComponentName, service: IBinder) {
            // Cast the IBinder to your generated interface stub
            aidlService = IMyAidlInterface.Stub.asInterface(service)
            isBound = true
            Log.d("MainActivity", "Connected to AIDL Service")

            // Safe to call methods once connected
            val result = aidlService?.add(10, 20)
            Log.d("MainActivity", "Result of add: $result")
        }

        override fun onServiceDisconnected(className: ComponentName) {
            aidlService = null
            isBound = false
            Log.d("MainActivity", "Disconnected from AIDL Service")
        }
    }

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)
        setContentView(R.layout.activity_main)

        // Bind to the Service
        Intent(this, MyAidlService::class.java).also { intent ->
            bindService(intent, connection, Context.BIND_AUTO_CREATE)
        }
    }

    override fun onDestroy() {
        super.onDestroy()
        if (isBound) {
            unbindService(connection)
            isBound = false
        }
    }
}
```

## Important Best Practices for Android 14+

+ Background Service Restrictions: Android 14 strictly enforces background execution limits.  
  If your service is starting from the background or performing heavy operations,  
  ensure you manage foreground service types properly if it escalates to a foreground service, or rely purely on bounded request-response lifetimes.
+ Cross-App Security (`exported="true"`): If your service communicates across different applications (inter-app IPC),  
  ensure you validate the caller's package name or implement signature-level permissions in your manifest (android:permission)  
  to prevent malicious apps from hijacking your service endpoints.
