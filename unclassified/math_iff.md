# math iff (if and only if)

## Definition: necessary/sufficient

+ A condition A is said to be necessary  for a condition B.  
if the falsity of A guarantees the falsity of B.

+ A condition A is said to be sufficient for a condition B.  
if the truth   of A guarantees the truth   of B.

## Conclusion

Sometimes, it is easier to specify necessary conditions than sufficient ones.

1. necessary  condition: if A' then B'
2. sufficient condition: if A  then B

## if A then B

A is sufficient condition for B.  
B is necessary  condition for A.

A: antecedent  
B: consequent

## if set A includes set B, it means set A is larger then B

if A' then B' and if B then A.  

+ A is a necessary  condition for B.  
+ B is a sufficient condition for A.

## if and only if

A if and only if B  
(A if B) and (A only if B)

1. (A if B)      = if B then A = B implies A = 'B => A'
2. (A only if B) = if A then B = A implies B = 'A => B'

So, iff means:  
> A is equivalent to B.  
A is a necessary and sufficient condition for B.  
(A implies B) and (B implies A)  
(A => B) and (B => A)  
A <=> B
